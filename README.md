## Local Development

To test FretPulse locally, you can use [Ghps](https://github.com/sepandhaghighi/ghps) a minimal GitHub Pages simulator written in pure Python.

Run:

```console
ghps --port 8000
```

Then open your browser and visit:

```console
http://localhost:8000
```
